# Léxica Mobile visual direction

## Product

An offline-first companion for professional translators. Its main jobs are to organize translation projects, keep client glossaries, record approved term choices, and consult external translation resources.

## Visual identity

- Palette: paper \`#F5F7F6\`, ink \`#142A3A\`, muted slate \`#61727C\`, proofing coral \`#E36550\`, marker yellow \`#F3D66B\`, quiet mint \`#DCEBE5\`, and white \`#FFFFFF\`.
- Typography: platform system sans for controls and body; restrained semibold display headings. Translation text gets generous line spacing and clear source/target labels.
- Layout: compact editorial cards with one strong ink header and a persistent bottom navigation bar. Forms use native touch controls and scroll naturally above the keyboard.
- Signature: a small yellow proofreader mark beside each translation pair, echoing a translator's annotation without obscuring the text.
- Shape: 18 px cards, 12 px controls, thin cool-gray borders, no decorative gradients.

## Runtime mapping

\`src/theme.ts\` is the source for runtime colors, spacing, radii, and type scale. Keep these tokens in sync with this file.
